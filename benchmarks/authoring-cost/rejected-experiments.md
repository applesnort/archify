# 未采用与预检失败记录

## 本轮产品范围之外

- Git helper、浏览器等待和路由算法：上一轮已有实现，本轮尚无观测支持继续改动；固定 B 的渲染器和验收器。
- 降低模型或推理配置：正式作者统一 GPT6 high，不用 Luna 的时延替代作者对比。
- 全仓库缓存/重型索引：尚无重复读取证据，不实施。

## 环境预检（不计为作者性能样本）

- 外层 sandbox 最初拒绝目录元数据，导致 Codex 无法 canonicalize 隔离 CODEX_HOME。改为拒绝文件数据读取、允许祖先目录元数据；后续模型可用性探测成功。
- Chrome 嵌套 sandbox 初始化失败。保留外层访问隔离，统一使用关闭 Chrome 内层 sandbox 的启动包装；四个 finalize gates 预检通过。此调整应用 A/B/C，质量检查未变。

正式实验结果及产品候选裁决待实际运行后追加。

## 基线适配错误与纠正

第一轮固定展示样例对照误向A的`check`传了新版`--require-provenance`。
A原生命令不支持该选项，也没有B的持久化交付sidecar。这些尝试保留为
适配错误，不记为A产品质量失败；在新目录用A实际支持的参数补测。
对A产物改用其原生deliver输出中的输入/产物哈希做外部绑定，不伪造sidecar。
普通作者未重跑，36次预算未扩大。A3真正失败的是原生visual-check视口溢出，
而非缺少新版sidecar；B重新渲染A的JSON所得几何诊断也不能冒充A产物的指标。

## 不采用机器波动作为本轮收益

B/C渲染器、Schema、校验器字节相同，固定输入产物也相同。两组几百毫秒以内
的时延差异只能作为观测波动，不能归因于Skill说明。固定机器阶段C相对A的
既有改进也不能归因于本轮指引与示例。

## 开发首样本的环境影响

`dev-01-A` 的 zsh heredoc 在外层 sandbox 下无法建立默认临时文件。独立复现：仅 TMPDIR 时 exit 1；另设 TMPPREFIX 到隔离工作区后 exit 0。该样本保留并计入 36 次，不替换，不将其时延差异归因于产品；后续组统一使用修正环境，holdout 尚未开始。环境修正不改变产品代码或质量门槛。
